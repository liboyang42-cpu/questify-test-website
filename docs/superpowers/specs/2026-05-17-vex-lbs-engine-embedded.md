# VEX LBS 任务链引擎 — 实现需求

## 定位

骰子检定下面再加一个插件：LBS 任务链引擎。骰子展示的是「数值运气」，这个展示的是「在城市里穿梭做任务的感觉」。不是真实上线的工具，是一个概念展示 demo。

## 最终效果描述

### 进入场景

点击左侧插件列表里的 LBS 任务链引擎，右侧画面会变成这个样子——

暗色调的上海市区地图铺满整个面板，地图的风格是深色赛博夜景：道路是发光的蓝色细线，建筑是深灰色块，黄浦江是暗青色。整个地图像是从无人机俯瞰的夜上海。

背景里有一些微弱的粒子在缓缓漂浮，和骰子那个粒子场风格一致，但更稀疏、更暗，起到氛围作用但不会抢地图的视觉。

### 操作流程

**第一步：在地图上点位置**

你在地图上点击，每次点击会落下一个发光标记。第一个点是绿色的光芒标记，写着「起点」。后面每点一下，就多一个标记，从小到大发光数字显示顺序。最多可以点 5 个点。

每一个标记落下去的时候，会有一个小小的光晕扩散动画——像往水面扔了一颗石子，光圈从标记处向外扩散一圈然后消失。

点击的时候地图不会缩放或移动，标记稳稳地落在你点的地方。

**第二步：规划路线**

点了至少 2 个点之后，右下角会出现一个「规划路线」按钮，同样是 liquid-glass 透明玻璃质感。

点击按钮：
- 按钮变成 loading 状态，转圈几秒
- 地图上标记之间出现路线

路线是一条流动的发光线条，从起点出发，经过每一个途经点，到达终点。线条不是死板的——它本身在用流光动画不停地从起点流向终点，像一条光河。

路线旁边会浮出一个小信息卡，显示这个行程的总距离和大概用时。

**第三步：看路线效果**

路线生成的同时，有 3 个额外的视觉效果：

1. **粒子流动** — 一些微小的发光粒子沿着路线路径从起点向终点移动，三五成群，像萤火虫在路线上飞行
2. **节点脉冲** — 起点保持稳定的绿色光晕，途经点有微弱的蓝色脉冲光晕，终点是金色光晕，像呼吸灯一样缓缓明暗变化
3. **路线发光** — 路线本身有微弱的辉光晕染，像是激光在夜空中留下的余晖

**第四步：玩完后**

可以在地图上空白处点击右键（或者点一个清空按钮），所有标记和路线消散，粒子向外飘散消失，地图恢复干净状态，可以重新开始。

也可以点左侧其他的插件，切换回去再回来时，恢复干净的地图状态。

### 交互反馈细节

- 鼠标移到途经点上时，标记会放大一点
- 路线规划完成后如果图上有多个路线方案（驾车 vs 步行），可以在路线信息卡旁边切换，路线颜色变化
- 如果规划失败（例如起点终点太近），画面会有一个轻轻的抖动，然后出现提示文字

### 特殊情况

如果腾讯地图的 API Key 没有配好，或者网络加载失败——插件不崩溃，而是自动切换到这个视觉效果：没有真实地图了，但保留深色背景和漂浮粒子，标记之间直接用 CatmullRom 曲线画出流动的光线路径，效果像一个抽象的发光拓扑图，依然好看。

> 这个降级模式不是偷懒的方案，而是本来就设计好的双模式。有 Key 看真实地图，没 Key 看抽象拓扑，都帅。

## 技术范围说明

- 需要腾讯地图 JS API GL（小程序买过的那个 Key）
- Key 放 .env 文件里
- 两个渲染层叠在一起：底层是腾讯地图，上层是 Three.js 透明玻璃层做粒子光效
- UI 控件（按钮、路线信息卡）用 DOM 浮层，复用已有的 liquid-glass 样式
- 保持和骰子一样的生命周期：进去初始化，切走清理干净

## 视觉风格

整体延续网站现在的暗色电影美学，不引入任何明亮/白色元素。地图本身要调成暗色主题。粒子光效要克制、精密、高质量，不要俗气的烟花效果。

参考感觉：Tron 的光路线条 + 银翼杀手的城市夜景 + 诺兰电影那种沉稳不张扬的科技感。
